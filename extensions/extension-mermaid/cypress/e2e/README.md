# extension-mermaid E2E

Clean-room Cypress suite against `test/playground/main.ts` via `@docs.plus/playground` (`docs-playground` on port 5178). Loads built `dist/` like an npm consumer. `?view=custom` mounts a host view, `?readonly` makes the editor read-only, and `?bare` turns off fold, copy and the Syntax link.

The suite has no load-error case. The playground bundles Pele into its main script, so no network request can fail there. It was checked once by hand in the docs.plus app, offline. No spec guards it.

| Spec                        | What it proves                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `render-states.cy.ts`       | A diagram draws under the source; a broken one shows its error at once on load but waits 1000 ms after the last edit; a type change redraws; a custom view mounts; the limit error names the limit and the count                                                                                                                                                                                         |
| `insert-command.cy.ts`      | `insertMermaid` leaves the caret at the end of the new source, mid-paragraph and at a paragraph start, and refuses inside a code block                                                                                                                                                                                                                                                                   |
| `markdown-round-trip.cy.ts` | A `mermaid` fence in backticks or tildes stays a diagram; `Mermaid` stays plain code; empty and invalid sources survive byte for byte                                                                                                                                                                                                                                                                    |
| `html-round-trip.cy.ts`     | `getHTML()` holds no SVG and `setContent()` restores the same document                                                                                                                                                                                                                                                                                                                                   |
| `fold.cy.ts`                | Fold is remembered per viewer; a caret in a folded source opens that block only, without storing, and an arrow key onto a folded block opens it, tested with a real key press; read-only starts folded; the head can be turned off; Copy confirms and resets; the faded label takes no clicks                                                                                                            |
| `complex-flowchart.cy.ts`   | A 33-node flowchart with nested subgraphs, every shape and edge style draws in full; RTL, CJK, emoji and long labels stay whole; label text and `click` lines never become live markup; 500 edges draw and 501 refuse, chained arrows counted one by one; an edit redraws in place; read-only starts folded and still draws all of it                                                                    |
| `complex-charts.cy.ts`      | One complex case for each of 20 other Pele types draws as its own type, with every label and the shape counts the source asks for                                                                                                                                                                                                                                                                        |
| `complex-documents.cy.ts`   | Nine diagram types in one document keep their own state and order; a broken block never touches its neighbours; fast edits across blocks each end on their latest source; Markdown and HTML round trips keep every source; delete and undo; read-only; paste keeps diagrams as diagrams                                                                                                                  |
| `edge-sources.cy.ts`        | Empty-like, frontmatter, directive, CRLF, BOM and keyword sources reach the right state; error lines after frontmatter keep their mapping; `accTitle` and `accDescr` become the SVG name; `<<choice>>`, `<<fork>>` and `<<join>>` follow Mermaid's declare-first rule; hostile styles, `themeCSS`, `click`, links and images never become live markup or a request; very long lines never widen the page |
| `edge-editing.cy.ts`        | Language switch, paragraph switch, real typing, undo and redo across types, select all and delete, arrow keys in and out, a runtime read-only toggle, removal while the renderer loads, hidden then shown, a 40-diagram document, Copy with Unicode, and a whole-document replace that keeps the drawn SVG                                                                                               |
| `edge-a11y-theme.cy.ts`     | Tab reaches the named head buttons; no live region in any state; coarse pointers get 44px buttons and no zoom; reduced motion drops every transition; theme changes recolour in place; dark text keeps 4.5:1; zoom keys and caret keys stay apart; print shows the right half of each block; a runtime inline theme style does not rebuild the block                                                     |

Fold specs end the document with a paragraph. A caret inside a folded source opens it when the block is built, so a bare block cannot stay folded after `setContent`. The caret rule wins over a remembered fold, because hidden source must never hold the caret.

Run: `bun run test` from this package (`pretest` build → playground → Cypress).
