# extension-hyperlink E2E

Clean-room Cypress suite against `test/playground/main.ts` via `@docs.plus/playground` (`docs-playground` on port 5173). Loads built `dist/` like an npm consumer.

## Specs

Reported integrations also run through `transaction-edit.cy.ts` and `labeled-preview.cy.ts`.
These cover direct and chained edits, visible preview labels, and operation without a metadata service.

## Harness conventions

- **Link icon params** — `icons=element|throw|map|fetcher|both` and `tile=on`. The icon PNGs live in `test/playground/icons/` and load from `/readme-media/<file>`. Each page load adds a `?run=` token to every icon URL, so the HTTP cache never hides a request across tests. Spy on them with `cy.intercept({ method: 'GET', pathname: /^\/readme-media\// })`, a RegExp, never a glob.

- **Navigate and gate params** — `navigate=spy` records each host `navigate` call on `window._navigateCalls` and opens nothing. `gate=strict` adds a host `isAllowedUri` that refuses `blocked.example`.
- **Hovercard params** — `hovercard=cover|adaptive` turns the card on. The stub counts calls on `window._hovercard` and answers after `delayMs` on the page clock, so `cy.tick` drives the dwell and the open. Each spec serves its pictures with `cy.intercept`. Fake only timers and `Date`: the engine shows a popover in a rAF, which Cypress also fakes by default.

- **`pressModK`** — focuses `#editor [contenteditable="true"]` then sends platform Mod+K (Ctrl on Linux CI). Use `focus()`, not `click()`, when a prior `selectText()` range must survive the shortcut.
- **Floating popover enter animation** — `.floating-popover` stays `opacity: 0` until `.visible` (next rAF in `@docs.plus/floating-popover`). Wait on the opened shell via `cy.getVisibleFloatingPopover()` (support/e2e.ts) before asserting popover content; BYO specs use `expectByoVisible()` (custom-popover.cy.ts).
