# Roadmap

Features that are designed but not built yet. Built behaviour lives in the guides listed in [docs/README.md](../README.md). Settled architecture lives in the [decision records](../adr/).

Nothing on this page exists in docs.plus today. Do not describe a feature here as shipped.

## Status

| Status   | Meaning                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Idea     | A thread in [GitHub Discussions, Ideas](https://github.com/docs-plus/docs.plus/discussions/categories/ideas). No design yet. |
| Proposed | An RFC in this folder, with research and open decisions. Nothing is built.                                                   |
| Accepted | The maintainer ruled on the open decisions. The RFC records each answer, and building can start.                             |
| Built    | The feature shipped. Its user guide moves to the main docs, and the RFC stays here as the record of why.                     |

## Add a feature

1. Start a thread in [Ideas](https://github.com/docs-plus/docs.plus/discussions/categories/ideas).
2. When the idea has a design, add a folder here named after the feature. Put `rfc.md` in it, and `research.md` when the research does not fit in the RFC.
3. Add one row to the Features table, and link the folder from the Discussion thread.
